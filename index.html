SOFTWARE LAB

CapCut & Alight Motion

Ab course mein sirf theory nahi—software ke andar actual workflow bhi hai. Neeche detailed step-by-step lessons aur video tutorials diye gaye hain.

01 — CapCut: First Project

Mobile aur desktop versions ke menu names thode different ho sakte hain, lekin basic workflow same idea follow karta hai.

Create a projectCapCut open karo → New/Create Project select karo.
Import mediaApne video, image aur audio files import karo.
TimelineMedia ko timeline par drag/add karo. Playhead se exact moment choose karo.
Save versionsMajor changes se pehle project ka version save karna useful hai.
Practice: 3 clips import karo, timeline par arrange karo aur ek 20–30 second sequence banao.

02 — CapCut: Cut, Trim & Transition

Clean editing ka base: unwanted moments remove karo, clips ko precise timing do, phir zarurat par transition lagao.

SplitPlayhead ko cut point par rakho → Split/Cut use karo.
TrimClip ke beginning/end ko drag karke timing tight karo.
DeleteUnwanted section remove karo aur gap check karo.
TransitionDo clips ko side-by-side rakho → transition control choose karo → duration adjust karo.
Mobile transition quick steps

Do clips ko timeline mein adjacent rakho → unke beech transition icon tap karo → transition select karo → duration set karo → preview.

Official CapCut transition guide ↗

03 — CapCut: Keyframes & Smooth Zoom

Keyframes se position, scale, rotation ya opacity ko time ke saath animate kar sakte ho.

Select the clipTimeline mein clip select karo aur transform controls kholo.
First keyframeStarting point par diamond/keyframe control press karo.
Move the playhead1–2 seconds aage jao aur scale/position change karo.
RefineExtra keyframes aur easing/speed controls se movement smooth karo.
Practice: 2-second slow zoom banao: 100% → 115%. Movement ko subtle rakho.
Official CapCut keyframe guide ↗

04 — CapCut: Auto Captions, Audio & Export

Speech ko captions mein convert karo, audio balance karo aur final file export karo.

Auto captionsCaptions → Auto Captions choose karo, language select karo aur generate karo.
Fix captionsNames, spelling aur timing manually check karo.
Audio mixVoice ko clear rakho; music ko itna loud mat karo ki speech cover ho jaye.
ExportResolution, frame rate aur format destination ke hisaab se choose karo, phir export karke file ko watch-check karo.
Official CapCut beginner guide ↗

01 — Alight Motion: Project & Layers

Alight Motion mobile/tablet-focused motion design workflow use karta hai, with multiple graphics, video and audio layers.

Create a projectNew project banao aur apna aspect ratio, resolution aur frame rate choose karo.
Add layersVideo, image, text, shape ya audio layers add karo.
Adjust layersPosition, scale, rotation aur timing set karo.
OrganizeLayers ko meaningful names/groups do so complex projects manageable rahen.
Video embed official quick-start series ka reference hai. App versions/device ke hisaab se menu placement change ho sakta hai.
Official Alight Motion Quick Start ↗

02 — Alight Motion: Keyframes & Easing

Keyframes se animation create karo, phir easing se movement ko natural feel do.

Choose a propertyPosition, scale, rotation, opacity ya supported property select karo.
Set keyframe 1Starting time par first keyframe add karo.
Set keyframe 2Playhead aage le jao aur property ki value change karo.
Apply easingEase-in, ease-out ya ease-in-out choose karke timing smooth karo.
Official easing guide ↗

03 — Alight Motion: Masking

Masking se layer ke specific area ko reveal/hide karke creative transitions aur composites bana sakte ho.

Prepare layersJis layer ko reveal/hide karna hai aur mask layer ko ready karo.
Create masking groupRelevant layers select karke masking/group controls use karo. Exact menu version ke saath change ho sakta hai.
Animate the maskMask position/shape ko keyframes ke through move kara sakte ho.
Preview & refineEdges check karo aur keyframes ko adjust karo so reveal smooth lage.
Official Alight Motion effects guide ↗

04 — Alight Motion: Effects, Motion Blur & Camera

Effects ko layer stack ke saath combine karo; advanced projects mein camera objects aur motion effects bhi use kiye ja sakte hain.

Add an effectLayer select karo → Effects se required effect choose karo.
Adjust parametersEffect controls ko small changes se tune karo; overuse avoid karo.
Use keyframesSupported effect parameters ko time ke saath animate karo.
Camera objectsComplex scenes mein camera object se position, rotation aur depth-style movement control kiya ja sakta hai.
